# AMR × AI Lab

**耐药菌科研人从零学 AI 的 96 天公开自学手册**

> 每天 1 小时学 + 1 小时写，16 周，产出 **96 篇文章 + 96 个可跑脚本**。
>
> 目标不是转行当算法工程师，是 **看懂原理、讲得清楚、用得明白**。

---

## 这是什么

**AMR × AI Lab** 是一个面向耐药菌（及更广的微生物 / 感染病）研究与检验同行的开源自学项目：把「从零学 AI」的全过程公开记录下来——**每天一个概念、一个可运行脚本、一篇写给同行看的文章**，96 天共产出 96 篇文章 + 96 个可跑脚本。

所有内容以实验室里天天在做的事当锚点——药敏表、MIC 折点、BLAST、PCR、生化鉴定条、MALDI-TOF 峰图——让没写过代码的检验人也能照着上手。

**适合谁**：微生物 / 感染病方向的科研与检验同行；以及任何想从零学 AI、并把它讲给同行听（写科普）的人。

**学习节奏**：每天 1 小时学 + 1 小时写（约 2 小时），周一至周六学习 + 发文、周日复盘，16 周共 96 个学习日。

### 三条公开承诺

1. **不神化 AI**。做不到的事会明确写「做不到」，每条边界结论都附上亲历或亲手验证的证据。
2. **每个术语都给实验室类比**。token ≈ k-mer，embedding ≈ 生化鉴定条的反应模式，注意力 ≈ BLAST 加权。不许裸抛黑话。
3. **每个数字要么亲手算出，要么标注来源与日期**。不引用未经核验的数据。

## 怎么用

### 1. 先把环境装好（约 30 分钟）

照 [`docs/ENVIRONMENT.md`](docs/ENVIRONMENT.md) 走，Windows / macOS / Linux 都有命令。

```bash
conda create -n amr_ai python=3.11 -y
conda activate amr_ai
pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
```

> ⚠️ **版本号以 [`requirements.txt`](requirements.txt) 为唯一依据**，不要照抄聊天记录里的二手转述。
> ⚠️ **千万不要 `pip install -U numpy`**：本项目锁 numpy < 2（torch 2.2.2 按 numpy 1.x ABI 编译，numpy 2.x 会崩）。

### 2. 每天 1 小时怎么花（另计 1 小时写作）

| 时间 | 做什么 |
|---|---|
| 0-5 分钟 | 复习昨天的「今天我学会了 ____」 |
| 5-35 分钟 | 学概念：看类比 → 看输出 → 自己讲一遍 |
| 35-55 分钟 | 动手：跑脚本，**改一个参数看结果怎么变** |
| 55-60 分钟 | 写一句「今天我学会了 ____」 |

每周一至周六为学习日，**周日复盘**（模板见 [`LEARNING_PLAN.md`](docs/LEARNING_PLAN.md) 第 2.9 节）。

### 3. 按天跟：`code/dayNN_*.py` ↔ `articles/dayNN_*.md`

每个脚本都带统一文件头（编号 / 主题 / 一句话作用 / 运行命令 / 预期输出 / 依赖 / 类比备注）。

```bash
python code/day01_first_python.py
```

跑完会在 `outputs/` 得到一张图，直接就能拿去当公众号配图用。

### 4. clone 下来能跑吗

能。每个脚本都不依赖外部文件（教学数据内联），图输出到 `outputs/`，且用相对脚本自身的方式定位路径——在项目根目录、`code/` 内、从其他路径调用都能跑通。

| 模块 | **Part 1 通用 AI 基础科普**（day01-48，阶段①②）：学通识，不要求读者做耐药菌研究，检验场景只作类比贴士 ｜ **Part 2 生信 AI 应用教学**（day49-96，阶段③④）：把 Part 1 落地到耐药菌课题做实战 |
| 阶段 | 4 个阶段各 24 天：①建立直觉 ②看懂模型 ③用起来 ④讲清楚+会判断（①②属 Part 1，③④属 Part 2） |

详见 [`docs/LEARNING_PLAN.md`](docs/LEARNING_PLAN.md)。

### 发布前三查（每篇必过）

1. 每个术语是否都带了类比？
2. 每个数字是亲手算出的，还是有来源与日期？
3. 有没有「AI 能替代某某」「AI 已经能做到某某」这类未经验证的断言？
4. **无第一人称自传（P0）**：主角须为中性「检验科研人」，个人背景（移动端经验、十年没写代码等）只能放在文末「作者注 / 学习笔记」，不得进入正文或用来立 flag；禁止「我写了十年 App」这类自传式开场。

四查不过，不发。
